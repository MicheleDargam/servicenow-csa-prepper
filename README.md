# ServiceNow CSA Prepper

App de estudo para a certificação ServiceNow CSA (Certified System Administrator): simulados, questões por domínio, timer de estudo (Pomodoro) e acompanhamento de progresso.

100% client-side (React + Vite + Dexie/IndexedDB) — não tem backend, cada pessoa guarda seu próprio progresso no navegador.

Publicado via GitHub Pages, deploy automático a cada push em `main` (`.github/workflows/deploy.yml`).
